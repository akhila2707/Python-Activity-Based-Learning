## About the Project

This repository contains Python Activity-Based Learning case studies developed as part of the B.Tech Computer Science and Engineering curriculum. Each case study includes a problem statement, objectives, assumptions, algorithm, flowchart, pseudocode, Python source code, test cases, output, and conclusion.

The programs use basic Python concepts such as variables, input/output statements, arithmetic operators, and conditional statements.

## Selected Case Studies

1. University Scholarship Allocation
2. Progressive Electricity Billing
3. Hospital Billing and Patient Classification
4. Employee Payroll and Deduction Analysis
5. Multi-Plan Telecommunications Cost Optimization
6. Railway Fare and Reservation Calculator
7. Retail Billing with Multiple Discount Rules
8. Manufacturing Cost and Profitability Analysis
9. Multi-Currency Travel Budget Analysis
10. Campus Event Financial Planning
